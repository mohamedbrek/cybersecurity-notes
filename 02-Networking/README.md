# 🌐 Networking Notes

Welcome to my Networking Notes!

Here I share my notes on all the things I'm learning about computer networks. As I study networking in college, through Cisco training, and practice, I use this repository to collect my notes.

Networking is the basis of cybersecurity, and I think that building a good networking background is a good step towards my future goal of becoming a cybersecurity professional.

---

## 🎯 Purpose

The main idea of this repository is to:

* Learn networking concepts
* Keep all my notes in one place
* Get a quick overview of topics before an exam or lab
* Make notes about network exercises
* Track my progress

---
